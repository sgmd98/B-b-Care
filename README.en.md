# BébéCare

**Child health, ages 0-5 : across all 15 ECOWAS countries.**
Health-facility map, AI triage assistant, official immunisation schedules,
WHO-standard malnutrition screening and a DHIS2 gateway.

## The problem

In West Africa, most deaths of children under five are **preventable**: a missed
vaccine dose, malnutrition spotted too late, a consultation delayed by three days.

Official WHO 2025 figures for the covered countries speak for themselves:

| Indicator | Value |
|---|---|
| Measles 1<sup>st</sup> dose coverage, Benin | **49%** |
| Measles 2<sup>nd</sup> dose coverage, Benin | **23%** |
| Pentavalent 3 doses, Benin | 69% |
| Under-5 mortality, Niger | **> 100 per 1,000** |
| Wasting (children under 5), Benin | 8.3% |

The information that would save these children **already exists** : but it is
locked inside ministry PDFs, WHO spreadsheets and DHIS2 databases that no parent
can reach.

## The solution

One web app, **free**, **usable without an account**, in French and English,
running on a low-end phone.

| Module | What it does | Official source |
|---|---|---|
| 🗺️ **Care map** | 23,568 health facilities across 15 countries, vector clustering, "near me", directions, phone numbers | OpenStreetMap (ODbL) |
| 🤖 **AI assistant** | Describe symptoms in plain language; the AI extracts age, temperature, duration and danger signs, then routes the caregiver | In-house NLU + IMCI (WHO/UNICEF) |
| 💉 **Immunisation record** | The country's **real national schedule**, computed due dates, overdue detection, `.ics` calendar export | WHO/UNICEF : *Vaccine schedule* (WIISE) |
| ⚖️ **Nutrition screening** | Weight-for-age, height-for-age, weight-for-height z-scores + MUAC, growth charts | WHO Child Growth Standards (LMS tables) |
| 🩺 **What should I do?** | Emergency / consult / monitor guidance, via questionnaire | IMCI algorithm (WHO/UNICEF) |
| 📊 **Data & DHIS2** | Immunisation coverage read **live** from DHIS2 + generation of a valid `dataValueSets` payload | DHIS2 API + WHO GHO (WUENIC) |
| 👤 **Account** | Country and language remembered, multi-child follow-up, measurement history | SQLite, PBKDF2 240,000 iterations |

> **The account is a bonus, never a toll gate.** Every module stays fully usable
> in guest mode. Signing in only syncs a child's follow-up across devices.

## The AI assistant, and why it is safe

The assistant takes a free-form sentence : *"my 8-month-old has had diarrhoea for
3 days and won't breastfeed"* : and turns it into a traceable clinical decision.

```
Free-form sentence
   └─ Bilingual FR/EN NLU   ~30 clinical signs, spelling correction
      (edit distance), negation detection, extraction of age,
      temperature, respiratory rate and duration
        └─ Deterministic IMCI engine (WHO/UNICEF)
             └─ Verdict: 🔴 emergency · 🟠 consult · 🟢 monitor
                + targeted follow-up questions
```

Three deliberate architecture decisions, defensible in front of a jury:

1. **The clinical recommendation is never generated by a language model.**
   The LLM decides nothing: the NLU understands, the WHO IMCI algorithm rules.
   No hallucinated medical advice is possible.
2. **Zero API keys, zero external calls.** The AI runs entirely server-side  : 
   free, scalable, and viable on a free hosting tier.
3. **Full transparency.** The UI always shows *"What the AI understood"*: every
   detected sign, its confidence score, the exact phrase that triggered it, and
   the signs discarded by negation.

BébéCare **makes no diagnosis** and says so on every screen.

## Why DHIS2 is the game changer

DHIS2 is the national health information system of 80+ countries, including
**14 of the 15 countries BébéCare covers**. Today, a community health worker
records vaccinations on paper and someone re-keys them into DHIS2 weeks later.
BébéCare removes that double entry:

1. **Live reads** : coverage indicators (BCG, Penta 1/3, measles, OPV 3) are
   pulled straight from the DHIS2 `analytics` API, by district.
2. **Standards-compliant writes** : the immunisation record and screening results
   are translated into a valid `dataValueSets` document, ready to be pushed into
   the national HMIS.

BébéCare **never connects to a national production database**: the demo runs on
DHIS2's official public instance (fictional Sierra Leone dataset, credentials
published by DHIS2). A ministry only needs to change three environment variables
to point BébéCare at its own DHIS2 : and writing stays disabled
(`BEBECARE_DHIS2_PUSH=0`) until they explicitly enable it.

## Architecture

```
api/                     FastAPI
  main.py                REST routes + serves the compiled front-end
  donnees.py             loading + 0.25° spatial grid index
  croissance.py          WHO z-scores (Cole LMS, adjusted tails)
  triage.py              deterministic IMCI engine
  ia_triage.py           bilingual NLU → clinical signs → triage.py
  comptes.py             SQLite accounts, PBKDF2-HMAC-SHA256, HMAC tokens
  dhis2.py               DHIS2 gateway (read, mapping, payload, validation)
  pays_meta.py           metadata for the 15 countries
web/                     React 19 + Vite + MapLibre GL + Recharts
data/
  pays/*.json            23,568 health facilities (15 files)
  calendriers.json       WHO national immunisation schedules, 15 countries
  who_couverture.json    WUENIC 2025 indicators
  who/croissance.json    WHO LMS tables (wfa, lhfa, wfl, wfh)
scripts/                 reproducible data-collection pipelines
```

Public-health data is **static and loaded in memory**: no heavy queries, sub-second
startup, deployable on a free tier. Only user accounts touch a database (SQLite,
a single file).

### The map

**Vector** MapLibre GL tiles served by **OpenFreeMap** (no key, no quota, no
watermark), native GPU-side clustering, three basemaps (Light, Muted, Terrain).
Points are loaded by bounding box: the server only returns what is on screen.

## Running locally

```bash
# API
pip install -r api/requirements.txt
uvicorn api.main:app --reload --port 8000

# Front-end (another terminal)
cd web && npm install && npm run dev
```

The Vite dev server proxies `/api` to port 8000.
In production, run `npm run build` and FastAPI serves `web/dist` directly.

### Environment variables

| Variable | Default | Purpose |
|---|---|---|
| `BEBECARE_DB` | `data/bebecare.db` | Accounts database path |
| `BEBECARE_SECRET` | *(random)* | Session-token signing key |
| `BEBECARE_DHIS2_URL` | public demo | DHIS2 instance |
| `BEBECARE_DHIS2_AUTH` | `admin:district` | DHIS2 credentials |
| `BEBECARE_DHIS2_PUSH` | `0` | Allow writes to DHIS2 |

> ⚠️ On Render the disk is ephemeral: mount a persistent disk (or switch to
> PostgreSQL) to keep accounts across deploys.

## Regenerating the data

```bash
python3 scripts/extract_osm.py        # health facilities (Overpass / OSM)
python3 scripts/fetch_who.py          # WUENIC coverage (WHO GHO)
python3 scripts/fetch_who_growth.py   # WHO growth LMS tables
python3 scripts/build_calendriers.py  # national immunisation schedules (WHO)
```

Every pipeline is **reproducible** and uses only open, citable sources.

## Privacy

- No trackers, no ads, no data resale.
- **Without an account**: the child's data stays in the phone's `localStorage`
  and never leaves the device.
- **With an account**: passwords hashed with PBKDF2-HMAC-SHA256 (240,000
  iterations), session token signed with HMAC-SHA256, valid 30 days. No health
  data is shared with any third party.
- Geolocation is only read when the user explicitly taps "Near me".
